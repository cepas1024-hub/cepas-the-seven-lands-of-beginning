# CEPAS — The Seven Lands of Beginning

A single-file HTML5 pixel adventure game (working title: AETHELGARD).

## Play locally
Open `index.html` in any modern browser (works great on mobile).

## Project
- Private repo; code + assets managed with Arena agent.
- Roadmap: finish HTML build -> package as Android APK (Godot/WebView) -> public release.
